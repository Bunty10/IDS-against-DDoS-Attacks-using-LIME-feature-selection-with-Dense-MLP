# IDS-against-DDoS-Attacks-using-LIME-feature-selection-with-Dense-MLP
Part of M.Tech Mini-Project used CICDDoS2019 dataset for the experimentation

Used DDoS data set (CICDDoS2019) that covers a large diversity and presents market scenarios and network traf-fic patterns. 

To investigate key and important features in the CICDDoS2019 dataset used different features derived using Local Interpretable Model-agnostic Explanation based on Data Analysis, and identify the important features using the LIME (Local Inter-pretable Model-agnostic Explanations) method. 

With the selected features, trained an Dense MLP model which is able to identify complex patterns among anomalies and train it to track and resolve them. 

However, the experiment proves that the proposed approach achieves high accuracy and recall but retains descriptive qualities that needed for real cybersecurity applications. 

Therefore, this analysis effectively balances powerful recognition with a general model that is easy to understand. It will improve network monitoring, and it can better quickly respond to DDoS attacks.
